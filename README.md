# Erzel — portfolio

Website: https://erzel-mo.github.io/

`site.zip` contains the static HTML, CSS, JavaScript, logo and 3D assets, preserving their directories. The four MP4 files are stored separately so every upload is below 25 MB.

GitHub Actions extracts `site.zip` and places the videos in `assets/` before publishing to GitHub Pages. The published site uses the original directory layout.

RU: ru-01.mp4, ru-02.mp4. EN: en-01.mp4, en-02.mp4.

To update the website, replace the relevant package or video and commit to main. See MODEL-CREDITS.md for third-party asset credits.
